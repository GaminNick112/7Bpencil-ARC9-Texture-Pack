# ARC9 Camo & Sticker Collection for 7Bpencil

A curated collection converted from selected Garry's Mod Workshop addons for 7Bpencil Weapon Camo and Stickers in SPT.

## Requirements

- SPT 4.1.x
- 7Bpencil Weapon Camo and Stickers 1.19.x

## Installation

1. Install 7Bpencil.
2. Download the latest release.
3. Extract into the SPT root.
4. Merge the included BepInEx directory.
